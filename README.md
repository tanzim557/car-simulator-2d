A lightweight, highly responsive 2D car driving simulator and vehicle kinematics engine implemented in pure HTML5 Canvas and vanilla JavaScript. Features realistic acceleration, friction, tire grip, and drift mechanics.

---

## Key Features

- Kinematic Vehicle Physics: Custom physics models incorporating engine acceleration, friction, angular velocity, and steering lock.
- Drift and Skid Mechanics: Dynamic loss-of-traction calculation when steering at high velocity with skid-mark canvas trails.
- Responsive Keyboard Controls: Smooth multi-key input handling (W/A/S/D or Arrow Keys plus Space for Handbrake).
- Live Telemetry Display: Real-time HUD showing speed in km/h, heading angle, and distance travelled.

---

## Getting Started

No dependencies required. Clone and open index.html:
```bash
git clone https://github.com/tanzim557/car-simulator-2d.git
cd car-simulator-2d

# Open index.html directly in any browser
start index.html
```
